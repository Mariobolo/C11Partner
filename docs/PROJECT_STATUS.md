## CSS优化技术要点总结

### 使用的高级CSS技术
1. **backdrop-filter**: 毛玻璃模糊效果
2. **box-shadow多层**: 外阴影 + 内发光 + 边框发光
3. **CSS渐变**: linear-gradient / radial-gradient
4. **cubic-bezier曲线**: 弹性动画效果
5. **transform 3D**: translateY + scale + rotateX
6. **filter**: drop-shadow + brightness
7. **::before/::after伪元素**: 装饰性元素
8. **!important优先级**: 确保样式生效(车载环境)
9. **浏览器兼容**: -webkit-前缀 + Firefox兼容
10. **硬件加速**: will-change + transform: translateZ(0)

### 设计原则
- **玻璃拟态(Glassmorphism)**: 半透明 + 模糊 + 边框
- **新拟态(Neumorphism)**: 软阴影 + 高光
- **微交互**: 悬停/点击/激活状态精细化
- **动效统一**: 弹性曲线 + 平滑过渡
- **无障碍**: focus-visible支持
- **性能**: 硬件加速 + 减少重绘
